# 扫描46离线训练产物包

该压缩包用于在部署好 `anjing-vision` 代码后直接恢复扫描46，不需要重新运行 SLAM3R、Gaussian 或语义训练。

包含：

- 扫描45基线训练数据（扫描46的点云基准）；
- 扫描46全部工作目录与补拍训练中间产物；
- 扫描46原始视频；
- 点云、2.5D/3D结构、长度测量、通行分析图和报告所需 JSON/PNG；
- 一键恢复脚本。

解压后，在 PowerShell 中运行：

```powershell
.\restore_scan46_bundle.ps1 -BackendRoot "D:\你的部署目录\backend"
```

然后启动项目。若目标数据库中没有扫描46记录，请在前端创建一个视频扫描记录并让维护人员将其工作目录指向 `data/work/46`；不要启动训练。

点云当前保持既有验收版本，本包不会继续修改或重新训练点云。
