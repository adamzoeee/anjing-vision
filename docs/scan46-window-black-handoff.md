# 扫描46窗边黑糊问题：数据交接与下一步修复

## 复现源机当前状态

先拉取 GitHub `main`，然后按顺序使用四个包：

1. `scan46_完整数据包.zip`
2. `scan46_最新结果补充包.zip`
3. `scan46_窗户增量补充包.zip`
4. `scan46_训练与补拍研究增量包_20260921.zip`

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File backend\scripts\deploy_scan46.ps1 `
  -FullBundlePath "D:\数据包\scan46_完整数据包.zip" `
  -SupplementBundlePath "D:\数据包\scan46_最新结果补充包.zip" `
  -WindowBundlePath "D:\数据包\scan46_窗户增量补充包.zip" `
  -ResearchBundlePath "D:\数据包\scan46_训练与补拍研究增量包_20260921.zip"
```

第四个包会覆盖为源机当前研究状态：`postprocess/preview_selection.json` 选择 `local_gaps_20260912.ply`。前三个包仍是正式可回退基线；不要删掉它们。补拍视频位于 `backend/data/training_sources/scan46_buchong2`。第四包刻意排除了失败的地图定位、重复点图和灰片/贴片候选，只保留修改窗户所需的重点数据，以便单个文件通过微信传输。

## 窗户补充视频（本次交接重点）

按以下优先级使用，不要把它们当成普通附件忽略：

1. `窗户边角2.mp4`：第一优先。覆盖窗帘下缘、靠垫、袋子及右侧黑区；现有 `target_r2_20260914` 21帧重建来自这段视频。
2. `窗户边角.mp4`：用于窗边角落、窗帘边界及大黑区归属核对。
3. `窗户那面墙/1000045072.mp4`：提供窗框、窗台、墙面等固定结构参照。
4. `窗户那面墙/窗户那面.mp4`：补充另一段窗户墙观测和刚性参照。

`书架上面2.mp4`、床头墙和橙色书架视频只用于邻近结构/床头缺口与定位辅助。窗帘属于软物体：同一局部表面只允许使用同一段连续视频中的状态，不能把以上四段视频的不同窗帘褶皱直接刚性融合。

## 当前问题，不要再误判为“只缺点”

窗口主体、窗框、窗台和左侧窗帘大体已经成型。主要缺陷集中在：

1. 窗帘右侧与书架之间的大面积黑区；
2. 窗框右侧到窗帘之间的错位、裂缝和错误遮挡；
3. 床靠窗、床头附近的黑区；
4. 左侧窗帘/墙面局部灰色贴片和模糊。

已经确认的事实：

- 单纯把 WebGL 点画大不能解决主黑区；
- 旧窗帘中部亮色横边曾被误认成真实下缘，19～22 厘米拉伸约束应废弃；
- `target_r2_20260914` 的21帧重建确实恢复出靠垫、袋子和窗帘下缘，但新旧相机/深度并未通过一致性验证，不能整块直接合入；
- 部分候选点存在却没有改善最终画面，原因可能是位置错误、旧点遮挡、颜色/稀疏显示或物体身份错误；
- 右侧黑区混合了窗帘、软物体、遮挡边界、窗外观测以及可能未被观测的空间，不能统一补成墙或窗帘。

## 推荐的最短可靠路线

不要再循环执行“加点—ICP/PnP—过滤—修接缝”。先用现有数据完成一次来源和遮挡审计，再只改有证据的表面。

1. **冻结正确主体**：窗框、窗台、暖气、现有窗帘主体、床、书架和其他房间点不动。
2. **按最终 WebGL 做来源分层**：同一固定视角分别渲染基线、R2候选、历史人工层，输出 RGB、深度和 point/source id。先判断黑区是无点、黑色点、被错误面遮挡、候选位置错误，还是没有可靠观测。
3. **按真实物体拆分**：窗帘右侧布面、靠垫、袋子、床品、墙面分别处理。不同物体不强制接缝；软物体只使用同一连续补拍片段，不混合不同时间的形态。
4. **先纠错再补**：仅在独立候选中撤回已证明错误的历史窗帘边缘/遮挡点。不得删除窗户主体。已有可靠点只修渲染或遮挡，不重新建模。
5. **缺几何时再恢复**：使用第四包中的原始补拍视频、`local_gaps_20260912`、`target_r2_20260914` 和各类审计结果。刚体锚点只负责定位；靠垫、窗帘、袋子不得参与相机求解。
6. **确实只有 RGB 的小区域**：只能做明确标记为 `visual-only` 的受约束局部展示面，不参与尺寸、结构和风险计算；正视与斜视均不能出现漂浮照片。

## 改好后的目标效果

- 右侧主黑区肉眼显著缩小，能辨认真实窗帘/靠垫/袋子或实际可见墙面，而不是灰色大平面；
- 中间错误亮条、裂缝和双层消失，窗帘边缘只有一层；
- 床头有真实观测的床品区域恢复，正常遮挡区不造假；
- 左侧不再出现新增灰片、厚片或颜色突变；
- 原有窗框、窗台、暖气及窗户主体外形和颜色保持不变；
- 正视、左右斜视、俯视和整屋视角都成立，无漂浮、重影、假墙和窗外点混入室内。

只有满足多视角视觉验收，才创建新候选；不要自动覆盖正式版本。若某块没有室内观测，明确标注“缺少什么视角/深度”，保留空缺，不制造假几何。
