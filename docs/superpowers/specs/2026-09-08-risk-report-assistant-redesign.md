# 风险报告与改造助手指标重构

本次修改仅覆盖空间指标、正式风险、报告展示和内存改造模拟，不修改点云、结构图底层数据及扫描产物。

- 主通道使用路径宽度中位数表示典型净宽；沿途最窄净宽表示瓶颈，只有瓶颈参与窄通道风险。
- 可活动空间使用入口可达的连续自由地面面积。
- 拥挤度使用家具占地并集面积除以房间有效面积，并同时返回两项面积。
- 家具间距、床离墙、旧床周边净空保留为兼容测量，不再单独评分。
- 床侧风险只使用不含贴墙侧的可使用侧净空。
- 通行图按净宽分绿、黄、红三级。
- 报告隐藏内部原因和空质量区，统一中文名称与 2D/参考尺寸文案。
- 多建议在同一内存几何副本中累计执行，再统一重算指标和评分。
