# 安龄智境——老人居住空间安全评估系统（高斯泼溅版）

## 1. 背景与目标

为老人居住空间（家中）提供**通行安全自动评估**：用普通手机拍摄房间照片，云端重建 3D 场景，自动检测门宽、通道宽度、门槛高度、坡度、台阶、临时障碍物等风险点，生成带可视化标注的评估报告与改造建议。

**核心转变**：放弃 Apple RoomPlan（仅限 LiDAR 设备 + macOS 开发），改用 **3D Gaussian Splatting（3DGS）**——任何手机拍照即可重建，开发全在 Python 生态，Windows + NVIDIA GPU 可跑。

## 2. 已确认决策（用户拍板）

| 项 | 决策 |
|---|---|
| 拍摄端 | Flutter 跨平台 App（iOS + Android） |
| GPU 训练 | 本地 RTX 5080（16GB VRAM），本地 Docker Compose 跑全部服务 |
| 采集方式 | **视频为主（随意录制）**：绕房间慢走一圈录 1~3 分钟视频即可；照片拍摄作为备选；后端 ffmpeg 抽帧 + 清晰度过滤
| 尺度标定 | 拍摄/录制时放置 A4 纸作为参照物（首选），先验兜底（标准门高 2m） |
| 视频采集 | 支持：用户随意录一段绕房间视频即可，后端自动抽帧 |
| 3D 展示 | 静态渲染图 + 交互式 3D 预览（App 内 WebGL 渲染高斯场景） |
| Web 后台 | 不需要，全部功能在 Flutter App 内 |
| 用户体系 | 多用户 + 机构管理（注册/登录/机构隔离/历史记录/改造前后对比） |
| 后端 | Python FastAPI 自建全栈（PostgreSQL + Redis + MinIO 对象存储） |
| 部署 | 本地 Docker Compose，云部署延后 |
| 时间 | 不排 8 周计划，按最优顺序一口气推进 |

## 3. 系统架构

```
┌─────────────────────┐
│  Flutter App        │  拍摄引导 / 上传 / 任务状态 / 报告查看 / 3D 预览
│  (iOS + Android)    │
└──────────┬──────────┘
           │ REST + WebSocket(任务进度) + JWT
┌──────────▼──────────┐
│  FastAPI 后端        │  auth / scan / report 模块
└──────────┬──────────┘
           │ 任务队列
┌──────────▼──────────┐      ┌──────────────────────┐
│  Celery Worker      │◄────►│  GPU 训练器           │
│  (重建+分析管道)      │      │  3DGS (nerfstudio)   │
└──────────┬──────────┘      └──────────────────────┘
           │
┌──────────▼──────────────────────────────────┐
│  PostgreSQL(元数据/报告)  Redis(队列)  MinIO(照片/点云/模型/渲染图) │
└─────────────────────────────────────────────┘
```

## 4. 核心流程（一次评估的完整链路）

1. **采集**：Flutter App 引导用户绕房间**录一段视频**（建议 1~3 分钟、慢走、角落停留；A4 纸放在显眼处作标定物）；也支持逐张拍照模式作为备选。
2. **上传与抽帧**：App 分片上传视频（或照片集）→ 后端 ffmpeg 均匀抽帧 + 清晰度过滤（Laplacian 方差剔除模糊帧），保留 100~300 帧作为重建输入。
3. **重建**：Celery 任务调 GPU 训练 3DGS（nerfstudio splatfacto 或 gsplat，Apache-2.0 可商用实现；**禁用** Inria 官方非商用实现），产出场景模型 + 稠密点云。
4. **标定**：在点云/渲染图中定位 A4 纸（SAM 辅助检测），换算全局尺度 → 得到真实尺寸点云。
5. **语义**：SAM + Grounding DINO 对关键帧做分割，2D mask 投影到 3D 点云，标注"床/沙发/桌子/杂物/宠物"等。
6. **几何分析**：RANSAC 平面提取（地面/墙面）→ 计算门洞宽、通道净宽、门槛/台阶高、地面坡度、高差。
7. **评分**：规则引擎按 PDF 标准打分（见 §5），生成风险列表 + 改造建议。
8. **报告**：渲染多角度标注图（Open3D/COLMAP 视图）→ 生成交互式 3D 预览资源（ply/gs 文件 + WebGL 渲染器）→ 写入报告。
9. **展示**：App 内查看报告、历史记录、改造前后对比（同一项目下两次扫描并排展示评分变化、风险项增删、标注图对比）。

## 5. 风险评估规则（源自 PDF）

| 指标 | 风险阈值 | 说明 |
|---|---|---|
| 门宽 | < 80cm 红 / 80~90cm 黄 | 轮椅通行 |
| 通道净宽 | < 90cm 红 / 90~120cm 黄 | 助行器/轮椅转弯 |
| 门槛高度 | > 2cm 红 / 1~2cm 黄 | 绊倒风险 |
| 台阶 | 存在且无扶手 红 | 每级高 > 15cm 记红 |
| 地面坡度 | > 5% 红 / 2~5% 黄 | 轮椅溜坡 |
| 地面高差/不平 | > 1.5cm 红 | 绊倒 |
| 临时障碍物 | 通道内出现 红 | SAM 语义 + 位置判断 |
| 卫生间门口 | 宽度 < 75cm 红 | 轮椅进不去 |

综合评分：分项加权 → 0~100 分（通行性 40% / 跌倒风险 40% / 无障碍 20%），每项附文字建议。

## 6. 模块划分

### 6.1 后端（Python）
- `auth`：机构/用户注册登录、JWT、机构数据隔离
- `scan`：评估项目（房间）、扫描任务、照片上传（分片）
- `recon`：3DGS 训练管道封装（模型选择、超参、GPU 调度、状态机）
- `analysis`：标定 → SAM 语义 → 几何分析 → 规则评分
- `report`：报告生成、静态渲染、交互预览资源打包
- `common`：配置、日志、MinIO/Redis/DB 客户端

### 6.2 前端（Flutter）
- 登录/注册（机构 + 成员）
- 项目列表 / 历史记录 / 改造前后对比
- 采集引导页（**视频模式为主**：录制提示——慢走、角落停留、避免逆光、放 A4 纸；照片模式备选）
- 上传与任务进度（WebSocket 推送）
- 报告页：评分卡片 + 风险列表 + 标注图 + 3D 交互预览（webview 嵌 WebGL 渲染器）

### 6.3 重建引擎（Python, GPU）
- 首选：nerfstudio `splatfacto`（Apache-2.0，成熟、好封装）
- 备选：`gsplat` + 自研训练脚本（更轻量，控制力强）
- 训练产出：`scene.splat`（高斯场）+ 稠密点云导出（深度图融合）

## 7. 技术选型明细

| 层 | 选型 | 理由 |
|---|---|---|
| App | Flutter 3.x | 跨平台，一套代码 |
| 后端 | FastAPI + Uvicorn | 异步、自动 OpenAPI 文档 |
| 任务队列 | Celery + Redis | 成熟、断点重试、进度上报 |
| 视频处理 | ffmpeg | 抽帧、关键帧提取、格式兼容 |
| 重建 | nerfstudio splatfacto / gsplat | Apache-2.0 可商用 |
| 语义 | SAM + Grounding DINO | 零样本分割，无需训练 |
| 点云 | Open3D | RANSAC、平面提取、渲染 |
| 数据库 | PostgreSQL 16 | 元数据、报告、用户 |
| 对象存储 | MinIO | S3 兼容，本地部署 |
| 部署 | Docker Compose（GPU 直通） | 一键起全部服务 |

## 8. 关键技术风险与对策

| 风险 | 对策 |
|---|---|
| **尺度未知**（最大风险） | A4 纸标定为主 + 门高先验兜底；标定失败时报告明确标注"尺寸未标定，结果仅供参考" |
| 重建失败（白墙/反光/暗角） | App 拍摄引导（提示补拍角度）；训练失败自动重试一次（降超参） |
| 训练时间长 | RTX 5080 预计 5~15 分钟/场景；进度实时上报 App |
| SAM 投影误差 | 多关键帧投票，点云标签取众数 |
| 高斯场 → 点云质量 | 深度图融合 + 统计滤波去离群点 |
| 视频画质差导致抽帧不足 | 抽帧质量过滤 + 自动补抽关键帧；仍不足时明确报错提示重录 |
| 交互预览体积大 | 高斯场压缩（sh degree 降级/剪枝），流式加载 |

## 9. 非目标（本期不做）

- 云上部署（延后）
- Web 管理后台
- 多语言
- 实时（秒级）重建
- 音频/语音辅助

## 10. 验收标准

1. 用户录一段绕房间视频（或拍照片集）→ 后端自动抽帧重建出带真实尺度的点云
2. 自动检出 PDF 中 8 类风险项中至少 6 类，输出评分与改造建议
3. App 能查看报告：评分、风险列表、标注图、交互式 3D 预览
4. 多机构数据隔离；改造前后两次扫描可对比
5. 全程 Docker Compose 一键启动（含 GPU 训练器）
