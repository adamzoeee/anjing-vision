## 接手修改重点

先保留交付基准，在独立候选中修改。重点是**书架—窗帘中段交界、窗框黑缝**，不要重新破坏已改善的床头、盒子/袋子和窗帘下缘。

1. 用相同正视/斜视/俯视核对：当前 `.visual.json` 的六层是否重复显示、窗帘右缘三角形是否错误遮挡书架；先做仅关闭可疑边面、不加点的A/B对照。
2. 查真实RGB、点图和构面索引，确认对象身份、深度跳变和边长。只撤掉有证据的跨物体三角面；不能把窗帘切直、拉宽或拉到书架。
3. 若书架确实缺表面，分侧板/层板/背板，用已有同板面定位、真实视频边界限定覆盖，不能用任意大平面填洞。SLAM3R不同裁剪曾产生深度偏差，不能直接叠成第二层书架。
4. 剩余窗框缝只处理确认误裁的真实折边、重复层和局部映射；不再启动全屋BA、标记打印或普通补拍循环。确实缺独立几何证据时明确指出具体面，不伪造。

验收：窗帘保持褶皱、不双层、不像厚贴片；书架侧更完整且仍是同一刚体；窗框缝缩小；床头不新增黑带；四视角没有新的漂浮、灰面或断层。程序运行成功不代表视觉达标。

无需模型权重、GPU或训练即可复现本次成品。若重新训练，结果不保证逐点一致；应先完整复现交付结果再修改。

## 大屏查看器坐标系校正（2026-10-09 修复）

现象：大屏 `#/scans/46` 家具框已正确，但点云在水平面上与框整体错开（用户描述“书架框在北、
点云的书架在东，像转了 90°”）。根因不是交付数据，而是**大屏前端只把水平面对齐用在了窗边
展示层上，点云逐点映射漏掉了这一段**：`addPointChunks` 当时只做竖直轴翻转
`(x, z, floor-y)`，而 `framePoint`（展示层）额外做了绕竖轴 180° 与整体尺度。

交付包 `window_wall_joined_20261008` 的坐标事实（只读复核）：

- 竖直轴是包内 Y、up = −Y：地板面在 y≈1.345，天花板侧在 y≈−0.49；窗边展示层（窗框、
  窗帘、床沿补片）的形状只有按“y 为高度”才成立，`views.front.R[1]=(0,1,0)` 也一致。
- 水平面绕竖轴 180°：包内 z 最小一侧是**窗+暖气片墙**（z≈−0.3），最大一侧是**门墙**
  （门扇在 z≈2.0，门缝处可见走廊几何到 z≈2.44）；包内 x 最小一侧是不对称的床头/挂画那面。
  只有 180°（包内最大角对准房间最小角）才能让门扇、窗洞、床、暖气片同时落进
  `structure_calibrated.json` 审计过的门框、窗框、`bed_001`。
- 尺度 1.1016：房间轮廓 (2.894×3.270) 与包内**真实极值** (2.626×2.968) 两轴比值为
  1.1022/1.1010，互相吻合 0.1%。分位包络（0.1%/99.9%）会切掉贴墙点，推出 1.133/1.188
  这种两轴不自洽的比例，所以拟合改成“两组输入里选两轴最一致的那组”，并在返回值里
  带 `source` 便于排查。
- 地板锚点改用竖直方向直方图里点最密的一层（`modalPlane`）。原来的 99.5 分位落在
  地板面之外的离群点上，会把整包点云抬高约 13cm。

修改点：`backend/app/static/console/js/viewer/frame.mjs`（`framePointInto` 为点云与展示层
共用实现，`fitHorizontalFrame` 双输入择优，`modalPlane`，`packUpAxis` 只用水平视角求竖直轴）
与 `pointcloud.js`（点云按 `framePointInto` 映射、地板/水平范围采样、状态栏显示是否已校正）。

验收（`backend/tests/test_console_frame_fit.cjs` 走真实交付包）：6/6 家具框落在点云上
（只修竖直轴时 4/6）；门扇质心 (1.95, −0.12, 1.10) 落在审计门框 x 段、窗洞质心
(0.27, 2.54, 1.69) 落在北墙窗框、床补片 100% 落在 `bed_001` 内；只修竖直轴时门会跑到
north 侧 y=2.09。点云映射后外接框 x[−0.483, 2.393] y[−0.49, 2.757]，与房间
[−0.484, 2.410]×[−0.501, 2.769] 基本重合。

已知残差（交付数据本身的性质，不是本次改动引入）：房间轮廓是视频关系图按点云**可见范围**
（含穿窗、门口走廊）定义的矩形，比点云墙体间距更深，所以北南方向上点云墙面会落在房间
线框内 0.1–0.4m；东西方向 0.05–0.15m。若要墙面完全贴合，需要重算房间轮廓（属于
`structure_calibrated.json` 口径变更），本次不动。
